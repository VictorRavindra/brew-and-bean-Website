# Brew & Bean — Café Website

A fully responsive website for a fictional neighbourhood café. **Concept project** built to show a complete small-business website.

**Live demo:** `https://<your-username>.github.io/brew-and-bean/`

## Features

- Responsive layout with a mobile hamburger menu
- Tabbed menu (Coffee, Tea, Bakes, All-day plates) rendered from JavaScript data
- Illustrated photo gallery with an accessible lightbox (Esc to close, focus returns)
- Table-booking form with validation (name, phone, date, time slots, guest stepper) and a confirmation message
- "Open now / Closed now" status that updates from the opening hours
- Illustrated map and opening-hours table
- Keyboard focus styles and reduced-motion support

## Tech

- HTML5, CSS3 (Grid, Flexbox, custom properties)
- Vanilla JavaScript — no frameworks, no build step
- Google Fonts: Fraunces and Work Sans
- All artwork is inline SVG, so there are no image files to manage

## Run locally

Open `index.html` in a browser. That's it.

## Deploy to GitHub Pages

1. Create a new public repository named `brew-and-bean` and upload these files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<your-username>.github.io/brew-and-bean/` within a minute or two.
